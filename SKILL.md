# Skills

Skills that must be installed on each project before writing any frontend code. Check if present and install if missing.

## Required Skills

| Skill | Purpose | Install command |
|---|---|---|
| `frontend-design` | Generates distinctive, production-grade frontend interfaces | `/plugin marketplace add anthropics/claude-code` then `/plugin install frontend-design@claude-code-plugins` |
| `web-design-guidelines` | Provides web design guidelines and best practices | `npx skills add https://github.com/vercel-labs/agent-skills --skill web-design-guidelines` |
| `find-skills` | Discovers and installs skills from the open agent skills ecosystem | `npx skills add https://github.com/vercel-labs/skills --skill find-skills` |
